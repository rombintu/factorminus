## Что сделано

- `config.py`: токен из окружения или `.env` (парсер на 10 строк), адрес MCP только `https://*.tbank.ru` (по умолчанию песочница), `tls_context()` = certifi + НУЦ Минцифры, SHA-256 от DER сверяется при каждом создании.
- `mcp.py`: `initialize` → `notifications/initialized` → `tools/call`, `Mcp-Session-Id`, JSON и SSE, `isError` и JSON-RPC `error` → `McpError`. Белый список из 9 инструментов проверяется до сети. Пауза 0,33 с, 3 попытки на 429/5xx/сеть, одна переинициализация на 404 с сессией. `-v` печатает инструмент, аргументы, время; токена в логе и `repr` нет.
- `db.py` + `schema.sql`: 4 таблицы, `CREATE TABLE IF NOT EXISTS`, миграций нет.
- `ingest.py`: карточка → актив → бренд (один вызов на бренд, уже известные бренды не запрашиваются) → свечи → ставки риска пачками по 50. Ошибка бумаги идёт в сводку. Повтор не дублирует строки.
- `iss.py`: веса IMOEX из ISS.
- `synth.py`: 23 бумаги `SYN_*`, 20 брендов, 1500 торговых дней, индекс `SYNIDX`; свойства в `EXPECTED`, проверяются тестом.
- `contract.py`, `wording.py`, 5 примеров в `docs/contract/examples/`.
- CLI `fm` на argparse: `demo synth check ingest weights stats call find reset`.
- `Dockerfile`, `compose.yaml` (один сервис `app`), `Makefile`, `.github/workflows/ci.yml`.

### Решения, которых не было в ТЗ

- **Свечи.** MCP не отдаёт дневные свечи за период больше ~2 лет (`maximum request period … exceeded`). Первая загрузка — `limit=2400` + `to=сейчас` (один вызов, ~9 лет), потом фильтр `date >= since`. Дозагрузка — `from=последний день` (он перезаписывается, т.к. мог быть неполным).
- **Ставки риска** приходят без `instrumentId`, только `instrumentUid`, в порядке запроса; у ненайденной бумаги `instrumentUid` пустой. Разбор по позиции, при несовпадении длины — ошибка в сводку. Из списка уровней берётся `STANDARD` и только если в карточке пусто.
- **Новое поле `instruments.asset_name`**: полное название актива («инвестиционные паи БПИФ … "Т-Капитал Индекс МосБиржи"»). Этапу 2 нужно для дубля по описанию.
- **`issuer` из `universe.yaml`** (2 облигации, выпущенные через финансовую «дочку») перенесён в `note` как «эмитент риска: …», чтобы не потерять.
- **Свечи выходных** хранятся как есть, будни отбирает этап 2.
- **`certifi`** указан в зависимостях явно: код импортирует его напрямую (он и так ставится с `httpx`).
- **uv в образе.** Бинарник uv подключается через `RUN --mount=from=…` только на время сборки: так образ на 34 МБ меньше.
- В `docs/CONTEXT.md` переписаны разделы 4 (стек, Docker, CI) и 10 (процесс), убраны `typer`, `TINVEST_INSECURE_SSL`, record/replay, этап 1.5. Справочник групп компаний (этап 2) указан в `src/factorminus/groups.csv` вместо `data/groups.yaml`: `data/` теперь в `.gitignore`. Сам файл создаст этап 2.

## Ревью

Ревью ветки (security + корректность): критичных проблем нет. Исправлено: повторное истечение сессии и не-JSON ответ давали трейсбек; переинициализация на каждый вызов, если сервер не отдаёт `Mcp-Session-Id`; `-v` не печатал неудачные вызовы; повторная загрузка карточки затирала `uid` и ставки (теперь `ON CONFLICT … coalesce`); синтетика отличается по `SYN\_%`, а не `SYN%`. Добавлена проверка уровня `STANDARD` в тест загрузки. Не исправлено: `--since` раньше прежнего не догружает старые свечи — описано в README (`fm reset`).
